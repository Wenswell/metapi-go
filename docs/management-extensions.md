# 标签筛选、上游分组与模型测试

## 本次范围

- 站点标签用于站点列表、账号管理、路由账号选择、分组列表与测试目标筛选，可组合关键词和原有筛选条件。
- 路由只在选择账号时筛选；保存的是所选账号，后续标签变化不改变路由。
- Groups 仅查询展示，不改变实际调用分组；包含单个/批量刷新、倍率、能力、描述、搜索与排序。
- 测试覆盖文本、图片、视频、Codex、Web Search；支持手动/定时执行、保存提示词与默认素材、历史搜索筛选及完整结果。
- 沿用 Metapi 组件、账号凭据、数据库与调度。参考项目只读取核心逻辑，固定适配两种新闻源，不移植账号导入、代理服务或样式。

## 实施顺序

| 阶段 | 所属代码 | 完成条件 |
| --- | --- | --- |
| 标签 | sites 表单/列表、accounts 列表、token-routes 账号选择 | 标签可编辑、持久化；全量筛选与分页计数一致；路由保存明确账号 |
| Groups | platform 分组适配、service 查询与存储、管理 API/页面 | 两类站点返回可比较分组；单项/批量结果、错误与时间可查看 |
| 测试 | 测试 service、scheduler、管理 API、model-tester 页面 | 五种类型使用保存内容执行；定时配置生效；结果逐项保存并可查详情 |

## 验证与交付

- 每阶段使用合成凭据和模拟上游验证受影响行为，不发起真实付费测试。
- 标签验证站点标签投影、账号分页筛选、路由搜索组合及隐藏选择保留。
- 分组验证 New API/Sub2API 响应、倍率与能力字段、批量部分失败和密钥脱敏。
- 测试验证各协议请求、错误记录、素材配置、定时目标与历史查询。
- 定向验证后集中执行前端检查/构建和后端检查；每阶段提交，工作区保持干净。
- 运行实例在验证完成前保持原样，部署使用独立镜像并先备份数据。

## 标签阶段完成

- 站点表单支持逗号分隔标签，API 返回标签数组；站点/账号列表与路由候选支持精确标签筛选。
- 账号标签条件在分页前应用，筛选总数与结果一致；路由筛选保留已有勾选，只批量选择当前匹配账号。
- 定向验证：后端站点标签创建/编辑/清空、账号分页及精确匹配通过；前端相关 49 项及新增组合筛选用例通过。
- 前端类型检查、构建、lint/模块边界通过；lint 保留上游已有警告。

## Groups 阶段完成

- 新页面「上游分组」按账号展示分组快照，支持标签、关键词、平台、图片/视频能力筛选和名称/倍率/站点排序。
- 批量刷新当前筛选账号，后台任务逐项记录成功/失败；单个失败保留上次成功分组，同时显示本次错误和尝试时间。
- New API 使用 `/api/user/self/groups`，Sub2API 使用 `/api/v1/groups/available`；使用账号访问令牌，不创建 API 令牌或改动路由。
- 定向验证涵盖两类上游响应、异常数据拒绝、凭据脱敏、失败保留快照和账号删除清理。

## 测试实施约定

- 新增「测试任务」入口，保留原有交互式模型测试。目标保存为明确的账号＋模型＋测试类型；标签仅用于选择目标。
- 账号调用使用已配置的可用 API 令牌；管理访问令牌不用于模型请求。测试直接访问账号所属站点，复用站点代理/请求头配置，不更新路由健康状态。
- 文本支持最多三轮上下文；图片使用 Chat Completions 图片输入；视频使用 Gemini generateContent 视频输入；Codex 使用 Responses SSE；Web Search 使用 `/v1/alpha/search`。
- 提示词、输出限制、超时与图片/视频素材 URL 或 data URL 保存在测试配置；手动和定时使用同一份配置。素材由上游读取或随请求发送，本服务不下载远端素材。
- 定时采用现有 cron 调度器，每分钟读取已保存计划；使用五段 cron 与显式 IANA 时区。停机期间不补跑，执行中不重叠运行同类任务。
- 每项目标独立记录成功/部分成功/失败、耗时、响应、错误与实际测试内容。历史按关键词、类型、状态、标签及日期查询，分页展示并可打开详情。

## 使用

1. 在站点编辑中填写标签，列表或账号选择器按标签与关键词组合筛选；路由仍保存明确选择。
2. 打开「上游分组」，选择标签/关键词后刷新账号；错误账号可以单独重试。分组能力来自上游字段，未提供的价格显示为空。
3. 打开「测试任务」，筛选账号、多选该账号已获取的模型并选择类型，添加目标；填写各类型内容与系统提示词，上传默认图片/视频或填写素材 URL 后保存。
4. 点击「运行已保存计划」，完成后查看本次批次或测试历史。历史可按标签、类型、状态、UTC 日期搜索，详情展示每轮输入、输出、usage 和耗时。
5. 需要定时执行时设置 cron 与时区并启用。保存后的明确目标不随站点标签变化；停机错过的时间不补跑。

## 可复用实现要点

- `sites.tags` 在 API 以数组返回；账号的站点标签条件必须在 SQL 分页前应用，不能仅筛选当前页。
- 分组属于账号可见范围，同一站点的不同账号可以不同；刷新失败时保留成功快照并明确记录错误。
- 管理访问令牌与 API 令牌职责不同。模型测试拒绝缺少 API 凭据的账号，避免把会话凭据发到模型接口。
- Codex 流必须出现成功的 `response.completed`；收到部分文本后断流仍算失败。Search 保留完整 JSON，不假设其与 Responses 的输出结构相同。
- 测试与分组请求使用完整站点配置，包含代理、自定义头和浏览器身份；现有账号 JOIN 只有部分站点字段，不能直接拿它代表完整配置。
- 模拟验证不会证明真实上游支持某协议；实际运行时错误保存在账号快照或测试历史中。

## 验证记录

- 五种协议均使用模拟上游验证请求；文本三轮上下文、图片/视频素材、Search JSON、Codex 完整终止事件通过。
- SQLite/PostgreSQL 定向验证：配置持久化、标签/状态/关键词历史查询、批次关联、部分成功、缺少 API 凭据、错误脱敏、定时与分钟去重通过。
- 浏览器联调：合成站点/账号 → 查询分组 → 保存计划 → 手动运行 → 按标签读取历史 → 打开每轮详情通过；运行实例和真实账号未参与。
- 前端静态检查、生产构建、358 个文件/2467 项测试通过；Go build/vet 和全量 race 检查已执行，配置键登记修复后复验受影响项与 store 全包。

## 管理交互修正

- 站点名称打开详情；网址列用于访问上游。账号列表展示所属站点标签。
- 分组页顶部是可折叠的刷新状态表，下方是分组明细表。四张新增表格共用现有表格功能：列配置、表头排序、分页、搜索和移动端视图；历史排序在服务端执行。
- 模型选择按所选账号汇总已有可用模型，支持多选，只添加账号实际拥有的模型组合；没有模型时先从账号详情刷新。
- 图片/视频可选择本地文件（单文件最多 6 MiB），预览、移除并保存；也可填写 HTTP(S) URL。
- 文本、视频、Codex 可配置各自的系统提示词；实际请求分别使用 system 消息、systemInstruction、developer 消息，详情保留实际提示词。
- 新闻源仅选择 Hacker News RSS（`https://hnrss.org/frontpage`）或 Spaceflight（`https://api.spaceflightnewsapi.net/v4/articles/?limit=20`）。提示词包含 `{NEWS-TODAY}` 时按需读取摘要；支持预览，失败停止批次，不调用模型。RSS/Atom 使用 gofeed，Spaceflight 使用专用 JSON 字段。成功摘要按来源与 UTC+8 日期缓存，近 24 小时最多 20 条，不足 10 条按来源顺序补齐。

## 导入导出

| 导出类型 | 新增内容 |
| --- | --- |
| 全部 `all` | 站点标签、账号分组快照/刷新状态、测试计划与历史 |
| 账号 `accounts` | 站点标签；沿用站点/账号/模型/路由范围，不含分组与测试 |
| 偏好 `preferences` | 完整测试计划：目标、系统/用户提示词、新闻源、图片/视频素材、定时规则 |

- 测试计划保存在 `settings.model_test_plan`；本地上传素材随计划导出，URL 素材只保存地址。新闻正文缓存不导出。
- 列显示、列宽保存在浏览器，筛选/排序/分页在 URL，均不属于数据库备份。
- 导入是合并，已有相同主键（设置为 key、分组快照为 account_id）跳过，不覆盖现有配置。备份预览会显示冲突。
- 单字段最大 20 MiB；结构化配置/分组/测试记录超限明确报错，不截断。整体导入最大 20 MiB，导出最大 64 MiB；大量历史迁移使用一致性数据库备份。
- 部署凭据、管理员令牌、WebDAV 配置等运行环境设置沿用现有导入排除规则。
