# 管理功能修正

## 范围与验收

| 需求 | 实施 | 验收 |
| --- | --- | --- |
| 站点名称 | 名称按钮复用站点详情入口，URL 保留独立外链 | 点击名称打开详情，和账号列表一致 |
| 账号站点列 | 修正站点投影/显示映射 | 已有账号显示所属站点名称 |
| 分组布局 | 账号刷新状态独立置顶、可折叠，分组明细独立表格 | 折叠不影响明细与刷新 |
| 新增表格 | 复用现有 DataTable、工具栏、列配置和分页/排序 | 分组两表、测试目标/历史均具备对应基础交互 |
| 提示词与新闻 | 文本/视频/Codex 系统提示词沿用参考语义；固定两种来源选项，按需替换 `{NEWS-TODAY}` | 保存后手动/定时共用；读取失败明确报告，不调用模型 |
| 模型选择 | 读取所选账号已保存的模型，支持多选；按账号实际模型生成目标 | 无自由输入，缺少模型提示先刷新，不生成无效账号模型组合 |
| 默认素材 | 文件选择、图片/视频预览、移除与单行 URL | 上传保存后重新打开仍可预览，实际请求使用所选素材 |

新闻源已确认：Hacker News RSS `https://hnrss.org/frontpage`、Spaceflight `https://api.spaceflightnewsapi.net/v4/articles/?limit=20`；仅选择、不编辑链接。不新增通用适配配置。新增解析优先复用成熟依赖和现有请求规则。

## 实施顺序

1. 修正站点名称与账号站点显示，完成定向验证并提交。
2. 统一分组及测试表格交互、模型选择和素材控件，定向验证并提交。
3. 系统提示词与两种固定新闻源贯通存储、执行和页面，定向验证并提交。
4. 更新使用文档，提交前完整检查一次；推送定制分支，备份并部署，核对数据与新增入口。

保持每轮提交后工作区干净；不发起真实付费测试。

## 实现与复查

- 站点名称与账号站点标签已修正；空标签列来自固定空数组 accessor 和缺失的账号所属站点标签投影，两处均已删除错误逻辑。
- 四张新增表格复用 DataTablePage/useDataTable/useUrlTableState；列宽与可见性使用现有持久化，搜索/排序/分页进入 URL，历史排序在 SQL 分页前执行。
- 模型选择复用账号模型查询；保存时校验账号、模型可用性及站点禁用模型。
- RSS/Atom 采用 gofeed 1.5.0；Spaceflight 是专用字段解析，固定源不提供通用映射。
- 浏览器素材预览需要 CSP 明确允许 data 与 HTTP(S) 图片/视频；仅调整 img-src/media-src，脚本与连接策略沿用原规则。
- 定向验证覆盖新闻解析与失败、系统提示词协议字段、模型组合校验、素材文件选择、表格状态与页面交互。

## 定制版本与备份复查

- 定制版本使用 `0.28.0-local.1`，更新包版本和变更记录；推送既有定制分支，构建带提交与时间信息的镜像，备份后部署。
- `all` 已由表注册表覆盖站点标签、分组快照、测试历史及 settings 中的完整测试计划；`preferences` 包含测试计划，`accounts` 仅保留原站点/账号/路由范围。
- 测试计划可含两个 6 MiB 素材，base64 后可超过旧的 4 MiB 单字段限制；导出/导入单字段上限统一为 20 MiB，覆盖合法计划与单次测试详情。
- 沿用整体导入 20 MiB、整体导出 64 MiB 限制；超过整体限制会明确报错，大量历史数据迁移使用一致性数据库备份。
- 验收使用合成数据执行导出→清空→导入，检查标签、分组、超过 4 MiB 的素材计划与历史详情；SQLite/PostgreSQL 均验证。完整检查仅在提交前执行。
- 浏览器列显示/列宽与 URL 筛选排序属于本机界面状态，不纳入数据库备份。导入沿用主键冲突跳过规则，不覆盖已有同键配置。
